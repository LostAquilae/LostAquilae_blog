# LostAquilae's Blog

My personal blog website, which showcases my work.

`npm run build` generates prerendered pages, a `404.html`, an RSS 2.0 feed, a sitemap, and a `robots.txt` file under `dist/`. The feed, sitemap, and robots file are available at:

- `https://lostaquilae.github.io/LostAquilae_blog/rss.xml`
- `https://lostaquilae.github.io/LostAquilae_blog/sitemap.xml`
- `https://lostaquilae.github.io/LostAquilae_blog/robots.txt`
